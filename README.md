# CAT3

Catalog of Astronomical Things

Desktop application for organizing astronomical observations.

## Features

- SQLite database for objects, observations, and images
- PySide6/Qt6 GUI
- Pre-loaded catalogs: Messier (33), NGC (18), Caldwell (10), Solar System (9)
- 70 astronomical objects ready to explore

## Requirements

- Python 3.x
- PySide6
- SQLite3

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python mainwindow.py
```
